# 💬 ChatBuddy AI

ChatBuddy AI is an intelligent, cross-platform chat application built with **React Native + Expo** that brings real-time AI conversations to Android, iOS, and the web.  
It connects to the **OpenAI API** to generate smart, human-like responses through a simple, responsive interface.

---

## 🚀 Features

- ⚡ Real-time AI chat with OpenAI integration  
- 💬 Clean, minimal chat interface with typing indicators  
- 💾 Message persistence and state management  
- 🌐 Works on Android, iOS, and Web (via Expo)  
- 🎨 Responsive design and smooth animations  
- 🔐 Environment-based API key handling  

---

## 🧠 Tech Stack

| Category | Tools / Frameworks |
|-----------|-------------------|
| Frontend | React Native (Expo) |
| Language | JavaScript / TypeScript |
| Backend / API | OpenAI API (via Axios or Fetch) |
| Routing | Expo Router |
| UI Library | React Native Paper / Custom Styles |
| State Management | React Hooks / Context API |
